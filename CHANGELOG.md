## [v2026.10.5-alpha] — 2026-10-18

### 🌟 Нові можливості та енергетичні профілі (New Profiles & Customization)
- **Два нові системні профілі живлення: SAVIOR та CUSTOM:**
  - **Режим Savior (Ультраекономія):**
    - Базовий екстремальний профіль живлення, розрахований на максимальну автономність (економніший за Eco в рази).
    - Миттєво перемикає екран на 60 Hz, повністю вимикає CPU Boost, переводить охолодження в Quiet, вимикає підсвічування клавіатури, примусово переводить dGPU в D3Cold, активує Windows Energy Saver.
    - Готова архітектурна база для подальшого розширення та глибокої оптимізації компонентів.
  - **Режим Custom (Користувацький профіль):**
    - Дозволяє користувачеві самостійно комбінувати параметри роботи системи в новому меню налаштувань.
    - Підтримує індивідуальне налаштування частоти оновлення дисплея (60 / 144 Hz), поведінки CPU Boost (Вимкнено / Стандарт / Агресивний), профілю вентиляторів Lenovo Vantage (Quiet / Balance / Performance), підсвічування клавіатури (Вимкнено / Низька / Висока) та енергозбереження Windows.
- **Вкладка Налаштування (Settings):**
  - Додано новий інтерфейсний екран із трьома скляними картками (Налаштування власного профілю Custom, Дія по кліку на іконку в треї, Інформаційна картка режиму Savior).
  - Швидкий доступ із нижньої панелі головного вікна `[⚙] Налаштування` або через контекстне меню трею.
- **Гнучке налаштування дії ЛКМ у системному треї (Tray Left-Click Action):**
  - Користувач може обрати в налаштуваннях один із трьох варіантів реакції на лівий клік по іконці в треї:
    1. Циклічне перемикання профілів: `Savior` -> `Eco` -> `Max` -> `Custom`.
    2. Відкрити або згорнути головне вікно (Toggle Window).
    3. Відкрити контекстне меню (Show Menu).
- **Оновлення контекстного меню та іконок трею:**
  - Додано 4 динамічні бейджі з колірною індикацією для кожного профілю: `SAV` (бірюзовий), `ECO` (зелений), `MAX` (помаранчевий), `CST` (фіолетовий).
  - У меню трею додано прямий вибір усіх 4 профілів із радіо-відмітками (checkmarks).

### 🐛 Виправлено (Fixed)
- **Ліквідація "забаганої іконки" (Tofu box `[▯]`):**
  - Замінено SMP-емодзі `🐞` (код U+1F41E, що виходить за межі базової площини BMP та не підтримується шрифтом Segoe UI у GDI+, утворюючи порожній прямокутник) на надійний BMP-символ `[!] Баг-репорт`.
  - Забезпечено суворе дотримання стандарту кодування символів BMP у всіх вікнах та меню програми.

## [v2026.10.4-alpha] — 2026-10-18

### 🌟 Нові можливості та інтерфейс (New Features & Universal UI)
- **Уніфікація управління процесами та кнопки оновлення на вкладках:**
  - На вкладку `▲ Графіка dGPU` додано кнопку ручного оновлення `[↻] Оновити` (ідентичну вкладкам CPU та iGPU) з негайним опитуванням відеокарти `GpuController::RequestImmediateProbe()`.
  - На вкладки `■ Процеси CPU` та `◇ Процеси iGPU` додано функціонал завершення процесів:
    - Кнопки панелі інструментів: `[X] Завершити процес...` (завершує найважчий за споживанням/навантаженням процес у списку).
    - Інтерактивна дія в таблиці: додано колонку `Дія` з червоною міткою `[✕]`; клік по будь-якому рядку таблиці відкриває запит на завершення обраного процесу (PID та назва).
    - Захист від збою системи: заблоковано завершення критичних системних процесів Windows (`dwm.exe`, `explorer.exe`, `csrss.exe`, `System`, PID <= 4), а також самого `EnergySavior.exe`.
- **Повноцінна система баг-репортів та зворотного зв'язку (Bug Reporting):**
  - Додано кнопку швидкого звернення `[🐞] Баг-репорт` у нижній панелі головного вікна поруч із кнопкою логів.
  - Додано пункт `[🐞] Повідомити про баг (GitHub)...` у контекстне меню системного трею.
  - Обидві дії автоматично відкривають каталог логів у Провіднику (`%LOCALAPPDATA%\EnergySavior`) та запускають у браузері сторінку створення нового тікета на GitHub проєкту (`APP_ISSUES_URL`).
  - `CrashHandler`: при непередбаченому збої (SEH Exception) вікно помилки тепер автоматично пропонує відкрити GitHub Issues разом із виділенням файлу дампу `.dmp` та логу в Провіднику.
- **Виправлення версіонування та префікса в заголовку:**
  - Ліквідовано зайву літеру `v` перед `alpha` у заголовку вікна: формат стандартизовано як `vYYYY.MM.PATCH-tag` (`v2026.10.4-alpha`).
  - Додано ревізійний лічильник збірок (Patch counter `.4`), щоб кожна нова версія мала унікальний номер та коректно підхоплювалася механізмом перевірки оновлень `UpdateManager`.
- **0-секундний відгук dGPU на старті:**
  - Усунено 30-секундну сліпоту при запуску програми разом із Wallpaper Engine чи іграми завдяки прапорцю `s_firstQuery` та скороченню лічильника сну `GPU_SLEEP_RECHECK_CYCLES` з 15 до 2 циклів.

### 🧪 Тестування
- Усі 29 автоматизованих юніт-тестів проходять з результатом 100%.

## [v2026.10.3-alpha] — 2026-10-18

### 🐛 Виправлено (Fixed)
- **Повне усунення Access Violation (0xC0000005) у `nvml.dll` при переході в D3Cold:**
  - Запит телеметрії живлення (`nvmlDeviceGetPowerUsage`) під час глибокого сну відеокарти (D3Cold / RTD3) більше не викликається при відсутності процесів, що запобігає збою драйвера.
  - Реалізовано апаратний ізолятор викликів драйвера через Windows Vectored Exception Handling (`SafeNvmlCall` / VEH): будь-який апаратний збій у закритій бібліотеці `nvml.dll` автоматично ізолюється без краху програми.
  - Визначення моделі відеокарти (`EnsureCachedGpuName`) оптимізовано через SetupAPI без пробудження відеокарти із D3Cold.

## [v2026.10.1-alpha] — 2026-10-18

### 🌟 Нові можливості та інтерфейс (New Features & Universal UI)
* **Повна універсальність програми (Universal Hardware):**
  * Видалено всі прив'язки до конкретних брендів (Lenovo LOQ / Legion) та специфічні BIOS-ідентифікатори із підзаголовка та футера.
  * Універсальний підзаголовок відображає виявлений процесор та відеокарту будь-якого ПК або ноутбука (`td.system.cpuName | td.gpu.model`).
  * Режими кулерів/TDP перейменовано на універсальні профілі продуктивності (`Режим охолодження (TDP): [Тихий] [Баланс] [Максимум]`).
  * Футер оновлено: *"EnergySavior: Розумний моніторинг та оптимізація енергоспоживання ПК та ноутбуків."*
* **Окрема вкладка енергозатратних процесів CPU (`■ Процеси CPU`):**
  * Високоточне нативне вимірювання навантаження на процесор у відсотках (CPU %) для кожного процесу через дельти системного та процесорного часу (`GetSystemTimes` / `GetProcessTimes`).
  * Відображення PID, імені виконуваного файлу, відсотка навантаження, оперативної пам'яті (RAM MB), розрахункової споживаної потужності (Вт) та категорії статусу (Високе/Помірне/Фонове навантаження).
* **Окрема вкладка процесів на вбудованій графіці (`◇ Процеси iGPU`):**
  * Автоматичне виявлення моделі вбудованого відеочипа (Intel UHD / Iris Xe / AMD Radeon) через `EnumDisplayDevicesW`.
  * Детектування та виведення списку активних GUI-додатків та апаратно-прискорених вікон робочого столу (DWM, Explorer, браузери, мультимедіа, IDE), які споживають живлення iGPU і не будять дискретну відеокарту.
  * Інформаційний блок про заощадження ~35-50 Ватт завдяки роботі додатків на iGPU замість dGPU.
* **5-вкладкова навігація з надійними символами BMP:**
  * Замінено SMP-емодзі (що спричиняли порожні квадрати `□` у шрифтах GDI+) на нативні Unicode BMP-символи:
    * `⚡ Головна` (Головний дашборд)
    * `◈ Графіки` (Історія споживання та графіки)
    * `■ Процеси CPU` (Енергозатратні процеси процесора)
    * `◇ Процеси iGPU` (Процеси на вбудованій графіці)
    * `▲ Графіка dGPU` (Дискретна графіка та Watchdog)
* **Підвищена точність та врахування всіх параметрів телеметрії:**
  * Споживання дисплея тепер безпосередньо враховує поточну яскравість екрану у відсотках у реальному часі через `DisplayController::CalculateDisplayWatts(hz, brightness)`.
  * У таблиці споживання компонентів явно відображається яскравість: `144 Hz | Яскравість: 80% (5.2 W)`.
  * Динамічний розрахунок споживання CPU на основі реального навантаження ядер і профілю Turbo Boost.
  * Усунено накладання тексту в блоці "БАЛАНС ЕНЕРГОСПОЖИВАННЯ": виділено ізольовані колонки компонентів, ватів і описів, замінено задовгий напис на `Сумарне споживання:`.
  * Повністю ліквідовано залишки пошкодженого кодування UTF-8 (виправлено `АКТИВНА` у блоці dGPU).
* **Розширено автоматизований тестовий набір до 28 юніт-тестів:**
  * 100% успішне проходження тестів навігації 5 вкладок, нових методів збору CPU/iGPU процесів, коректності символів і цілісності кодування.

## [alpha-2026.10] — 2026-10-17

### 🌟 Додано та Оновлено (Added & Updated)
* **Нова модульна вкладкова навігація (Tab Navigation):**
  * **`⚡ Головна` (Dashboard):** Очищена та простора головна панель без захаращення та накладання елементів. Картка споживання тепер має кнопку швидкого переходу до аналітики `[ 📈 Графіки ват → ]`.
  * **`📈 Графіки та моніторинг` (Graphs):** Великий високоточний графік споживання потужності в реальному часі (буфер на 60 секунд) із неоновою підсвіткою, розрахунком пікового (Max), мінімального (Min) та середнього (Avg) значень у ватах, а також розгорнуті картки здоров'я батареї та енергоспоживання компонентів.
  * **`💻 Процеси та пристрої` (Devices):** Повноцінний менеджер дискретної графіки NVIDIA GeForce RTX із таблицею активних процесів (ім'я, PID, зайнята VRAM) та можливістю індивідуального примусового завершення кожного процесу (`[ Завершити ]` для конкретного PID), а також картки системних девайсів (процесор, iGPU, дисплей eDP, зовнішні монітори, EC).
* **Виправлено роботу Windows Energy Saver ("WIN SAVER"):**
  * Виявлено та усунено блокування кліків у шапці вікна: кліки на кнопку `WIN SAVER` помилково перехоплювалися як жест перетягування вікна (`WM_NCLBUTTONDOWN`). Тепер клік на будь-яку кнопку обробляється миттєво з найвищим пріоритетом.
  * Інтегровано нативне перемикання оверлею живлення Windows 11 через `PowerSetActiveOverlayScheme` (`GUID_OVERLAY_ECO` та `GUID_OVERLAY_BALANCED`), що працює без потреби прав адміністратора.
  * Додано метод `TelemetryThread::RefreshPowerStatus()` для миттєвого оновлення стану кнопки на UI (0 мс затримки).
* **Повна українізація кодової бази та документації:**
  * Усі внутрішні коментарі у вихідних файлах C++ перекладено українською мовою.
  * Усі системні повідомлення журналу логів (`Logger`) українізовано.
  * Оновлено документ правил розробки `.agents/rules/development_rules.md` та `DEVELOPMENT.md`.
* **21 автоматизований юніт-тест (100% успішне проходження):**
  * Усі тести покривають конфігурацію, перемикач енергозбереження Windows, обчислення батареї, MUX, CPU Boost та систему оновлень.
* **Система перехоплення та діагностики крашів (`CrashHandler`):**
  * Повноцінна інтеграція **Structured Exception Handling (SEH)** через `SetUnhandledExceptionFilter` для виявлення `EXCEPTION_ACCESS_VIOLATION (0xC0000005)`, `EXCEPTION_STACK_OVERFLOW`, ділення на нуль тощо.
  * Автоматична генерація **Minidump (.dmp)** через `dbghelp.dll` (`MiniDumpWriteDump`) для відкриття у WinDbg та Visual Studio.
  * Збереження вичерпного звіту про збій `%LOCALAPPDATA%\EnergySavior\crash_report_YYYY-MM-DD_HH-MM-SS.log` зі станом усіх регістрів процесора x64 (RAX-R15, RIP, EFLAGS) та повним стеком викликів (Stack Backtrace) із зазначенням зміщень модулів.
  * Системне діалогове вікно з поясненням збою та кнопкою миттєвого переходу до файлів у Провіднику для відправки репорту розробнику.
  * Прапорець командного рядка `--test-crash` для перевірки надійності роботи краш-хендлера.
* **Автоматизований тестовий фреймворк (`tests/TestRunner.hpp`, `tests/TestMain.cpp`):**
  * **19 автономних юніт-тестів**, що перевіряють конфігурацію, логер, математику батареї, CPU Boost, Windows Power, Lenovo WMI, GPU Watchdog, SEH краш-хендлер та логіку порівняння версій оновлювача.
  * Однокліковий скрипт запуску `run_tests.bat` або `build.bat test` (виконання за ~50 мс).
* **Високопродуктивна збірка компілятором (аналог `cargo build --release` у Rust):**
  * Режим максимальної швидкодії: прапорці `-O3 -flto -march=x86-64-v2 -DNDEBUG -s`.
  * Зменшення розміру бінарного файлу з 357 KB до **155 KB** (>55% оптимізації).
  * Профілі збірки у `build.bat`: `release`, `debug`, `test`.
* **Крос-платформна підтримка та VirtualBox (Linux):**
  * Додано файл збірки `CMakeLists.txt` для компіляції та запуску тестового набору в середовищі Linux.

### 🐛 Виправлено (Fixed)
* **Виправлено раптовий виліт програми (Crash 0xc0000005 у `ntdll.dll`):**
  * Замінено виклики недокументованих функцій `PowerSetUserConfiguredACPowerMode` на безпечне стандартне системне Win32 API `PowerSetActiveScheme` з гарантованими схемами живлення Windows (`SCHEME_POWER_SAVINGS` та `SCHEME_BALANCED`).
* **Виправлено залежність активного режиму (Еко/Макс) від стану живлення та CPU Boost:**
  * `ApplyEcoProfile()`, `ApplyPerformanceProfile()` та `SetBoostMode()` синхронно змінюють як DC, так і AC параметри реєстру Windows Power (`PowerWriteACValueIndex` та `PowerWriteDCValueIndex`), а також ліміти троттлінгу процесора (99% для Еко, 100% для Макс).
  * Режим `isEcoMode` тепер зберігає явний вибір користувача і не перетирається автоматично.
* **Виправлено роботу MUX Switch (режими Hybrid, iGPU Only, dGPU Only):**
  * Виправлено виклик WMI-методу `SetIGPUModeStatus`: додано обов'язковий другий параметр `Data = [uint32]0` згідно з сигнатурою CIM/WMI ноутбуків Lenovo.
  * Додано інформаційне спливаюче сповіщення Windows про те, що перемикання апаратного MUX Switch потребує перезавантаження системи для активації на рівні BIOS.
* **Виправлено перемикання підсвітки клавіатури:**
  * Усунено втрату лапок та символів `$` при виконанні команд PowerShell через впровадження стандарту Base64 `-EncodedCommand` (Win32 `CryptBinaryToStringW`).
  * Реалізовано подвійний виклик: `LENOVO_GAMEZONE_DATA::SetKeyboardLight` та `LENOVO_LIGHTING_METHOD::Set_Lighting_Current_Status` для гарантованої сумісності з серіями LOQ 15IAX9.
* **Покращено інтерфейс та синхронізацію з треєм:**
  * У Hero-блоці розміщено дві виразні великі кнопки швидкого вибору: **`[ 🌿 ЕКО ] (60Hz + Quiet)`** та **`[ 🚀 МАКС ] (144Hz + Boost)`** з колірною підсвіткою активного режиму, що повністю узгоджується з логікою перемикання в системному треї.
* **Приведено версіонування до стандарту SemVer Alpha (`0.2.0-alpha` замість передчасних релізів).**

  * Автоматичне виявлення стану вбудованого **Windows Energy Saver (Battery Saver)** через `SYSTEM_POWER_STATUS::SystemStatusFlag`.
  * Зчитування та перемикання **Windows Power Mode (Overlay Schemes)** через API `powrprof.dll`:
    * Режим Еко: встановлює `Best Power Efficiency` (0) та синхронізується з режимом енергозбереження Windows.
    * Режим Продуктивність: встановлює `Best Performance` (2).
  * Динамічний бейдж у шапці програми: **`[ WIN SAVER: ON ]`** (зелений) або **`[ WIN SAVER: OFF ]`** (нейтральний).
* **Повноцінна багатопотокова система логування (`Logger`):**
  * Потокобезпечний запис подій у файл `%LOCALAPPDATA%\EnergySavior\energy_control.log`.
  * Запис усіх апаратних подій з мілісекундними мітками часу: старт/стоп, детекція заліза, перемикання AC/DC, зміна частоти екрану, режим охолодження, стан MUX, завершення процесів GPU.
  * Автоматична ротація файлу логів при досягненні розміру **2 MB** (створюється резервна копія `.old`).
  * Кнопка швидкого відкриття журналу подій **`[!] Журнал подій (Лог)`** у вікні програми та пункт у контекстному меню трею (відкриває лог у Блокноті в 1 клік).
* **Єдиний файл правил та стандартів розробки (`DEVELOPMENT.md`):**

## ↩️ Інструкція з відкату змін (Rollback Guide)

У разі виникнення будь-яких проблем у нових версіях, проект підтримує миттєвий відкат за допомогою Git:

### 1. Перегляд історії змін:
```bash
git log --oneline --graph --decorate
```

### 2. Повернення до стабільної версії 2.0.0:
```bash
git checkout v2.0.0
```

### 3. Відкат останнього коміту зі збереженням файлів:
```bash
git reset --soft HEAD~1
```

### 4. Повний відкат до попереднього робочого стану:
```bash
git reset --hard HEAD~1
```
