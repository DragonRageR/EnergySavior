# EnergySavior ⚡ (Native High-Performance GUI & Tray Agent)

Універсальна високоефективна нативна Windows C++20 програма для глибокого керування енергоспоживанням, автономністю та апаратними режимами ноутбука (динамічно виявляє конфігурацію: процесор, відеокарту, екран, BIOS, MUX Switch, підсвітку та датчики).

---

## 🌟 Ключові переваги та виправлення нової архітектури

### 1. Багатопотокова архітектура (Multi-threaded & 60+ FPS):
* **Окремий фоновий потік телеметрії (`TelemetryThread`):** усі запити до заліза (Win32 IOCTL для акумулятора, NVML для GPU, Windows Power API для процесора, WMI для Fn+Q/MUX) виконуються асинхронно у фоні (інтервал 1.5 с) і займають менше 0.2 мс.
* **UI потік абсолютно не блокується:** інтерфейс працює з частотою 60+ FPS без жодних затримок, фризів чи просідань.
* **Жодних викликів консолі `system()` чи `_popen()`:** усунуто спам чорних вікон та російськомовні повідомлення PowerShell/cmd. Всі виклики WMI проводяться приховано з `CREATE_NO_WINDOW`.

### 2. Керування у системному треї (Панель завдань Windows):
* **Лівий клік (ЛКМ):** миттєве перемикання 1 кліком між:
  * `[ECO]` **Енергозбереження:** екран **60 Hz**, CPU Boost **Вимкнено** (~2.4 GHz, без пікових стрибків 65W), тихий режим охолодження **Quiet** (Fn+Q).
  * `[MAX]` **Максимальна продуктивність:** екран **144 Hz**, повний CPU Boost до **4.4 GHz**, режим **Balance**.
* **Захист від спаму сповіщень:** виправлено помилку прапорця `NIF_INFO`, додано 5-секундний rate-limiter.
* **Захист від швидких мульти-кліків (Debounce):** атомарний прапорець запобігає збоям при швидкому кількаразовому натисканні.
* **Правий клік (ПКМ):** зручне контекстне меню (відкриття вікна, режими, авто-перемикач, автозапуск, вихід).

### 3. Розширений апаратний функціонал:
* **MUX Switch (Керування GPU):** вибір між `Hybrid (Optimus)`, `iGPU Only` (повне відключення dGPU для максимальної економії заряду) та `dGPU Only` (прямий вивід на дисплей для ігор).
* **Керування підсвіткою клавіатури:** перемикання рівнів підсвітки (Вимкнено / Низька / Висока) через фірмовий WMI.
* **Підтримка зовнішніх моніторів:** відображення підключення додаткових дисплеїв через HDMI / Type-C DisplayPort та попередження, якщо монітор утримує dGPU активною.
* **NVIDIA Watchdog та безпечне закриття процесів:** список активних програм на dGPU з PID (webwallpaper, Discord тощо) та кнопка закриття утримуючих процесів з захистом від переповнення тексту.
* **Універсальна детекція заліза:** автоматичне зчитування SMBIOS/Registry виробника, моделі ноутбука, версії BIOS та назви процесора (замість жорстко зашитого тексту).

### 4. Автозапуск та права Адміністратора:
* **Embedded Manifest (`requireAdministrator`):** програма автоматично стартує з підвищеними привілеями адміністратора (зелений бейдж `[ АДМІНІСТРАТОР ]`).
* **Відображення у Диспетчері завдань:** реєстрація у `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` з коректними лапками (виправляє помилку `Windows не може знайти C:\Program`).
* **Планувальник завдань (Task Scheduler):** запуск на рівні `HIGHEST` без запитів UAC при вході в систему та дозвіл роботи від батареї.

## 📁 Структура проекту

```
EnergySavior/
├── include/
│   ├── core/
│   │   ├── AppConfig.hpp          # Налаштування, автозапуск, UAC перевірка
│   │   ├── SystemInfo.hpp        # Універсальне зчитування SMBIOS / Registry
│   │   └── TelemetryThread.hpp   # Багатопотоковий воркер телеметрії та безпечний debounce
│   ├── hardware/
│   │   ├── BatteryController.hpp # Win32 IOCTL SetupAPI аналізатор акумулятора
│   │   ├── CpuController.hpp     # Windows Power Scheme CPU Turbo Boost
│   │   ├── DisplayController.hpp # GDI ChangeDisplaySettings (60/144 Hz)
│   │   ├── GpuController.hpp     # NVML моніторинг дискретної відеокарти
│   │   └── LenovoWmi.hpp         # WMI команди (Thermal Fn+Q, MUX Switch, Підсвітка)
│   └── gui/
│       ├── GuiWindow.hpp         # Сучасний GDI+ Dark UI з захистом від кліпінгу
│       └── TrayManager.hpp       # Іконка в треї, бейджі [ECO]/[MAX], меню
├── src/
│   ├── core/
│   ├── hardware/
│   └── gui/
├── res/
│   ├── app.manifest              # UAC elevation & PerMonitorV2 DPI
│   ├── app.rc                    # Ресурсний файл
│   └── app.res                   # Зкомпільовані ресурси
├── EnergySavior.exe.manifest     # Маніфест для Windows Activation Context
├── main.cpp                      # WinMain, черга повідомлень, безшовна ініціалізація
├── build.bat                     # Скрипт компіляції (GCC C++20)
├── install_autostart.bat         # Налаштування автозапуску
└── uninstall_autostart.bat       # Видалення автозапуску
```
